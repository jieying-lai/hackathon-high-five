# CareerLens：产品、商业与体验审查

审查日期：2026-10-23。基础版本：jie-ying / 8b3a096。这里的价格、目标和商业模式是实验建议，不是已验证收入、市场份额或效果承诺。

## 结论

目前是有完整故事的原型，不是已经建立市场优势的招聘平台。最值得集中解决的问题是：马来西亚毕业生缺少职业日常认知，也难以把课程、社团和项目转成雇主看得懂的能力证据。不要同时向所有求职者、所有企业推销所有功能。

建议定位：**先试做，再选择；把你的经历变成下一份工作的证据。**

用户路径应是：一个有趣的入口 → 了解职业实际工作 → 完成小任务或整理真实项目 → 自己审阅证据 → 选择目标岗位 → 明确授权申请 → 得到反馈。Quiz 可以帮助反思，不能决定就业资格；匹配分数是辅助，不应装成客观就业概率。

## 对比市场：哪里有机会，哪里没有

| 对比对象 | 官方产品已提供 | CareerLens 应避免的竞争 | 可验证的切入点 |
|---|---|---|---|
| MYFutureJobs | Career Hub 提供免费简历审核、辅导、匹配与注册协助 | 单靠 AI 简历整理向学生收费 | 把一次辅导接成可持续的练习、证据整理和行动进展 |
| JobStreet / SEEK | 雇主职位广告、人才触达与定向推广 | 用导入职位量伪装招聘网络；与成熟渠道争数量 | 给招聘渠道补充有上下文的候选人作品，提供真实的申请跳转 |
| Hiredly | 公司文化内容、雇主品牌页面和招聘服务 | 只做漂亮的公司卡片 | 本地初级岗位的日常任务、能力证据与结构化人工反馈 |
| Forage | 免费、由雇主设计的自定进度工作模拟 | 声称小任务或模拟本身是独创，或靠普通练习收费 | 试验本地 SME 共同设计的短任务与明确授权的作品审核 |

## 真正的帮助与界限

- 对毕业生：先接触实际任务，减少只凭职位名称选职业；整理真实经历，减少面对空白 CV 的困难。不能承诺就业率提升，必须通过试点比较。
- 对中小企业：减少只凭学校、头衔或华丽简历筛选，比较候选人的具体思考过程。仍须人工判断，不能把自评或趣味测验当招聘门槛。
- 对院校：将学生“浏览了课程”与“完成了一个可讨论的作品”分开，帮助辅导老师识别需要支持的人。院校管理与群组报告目前尚未建立。
- 对 AI 转型焦虑：给出一个可执行的下一步，比单独展示“岗位风险”更有用。趋势数据需要来源、更新时间和不确定性说明；不是失业预测。

## 怎样赚钱

先保持个人基础探索、练习和基本 CV 管理免费。不要出售个人 CV 或把广告付费混进匹配排序。

1. **SME 招聘试点**：收费提供岗位任务共创、结构化审核模板和人工反馈工作流。可用 RM299–599 / 月作为访谈与报价实验区间；这些价格不是市场报价，也不代表当前功能已足以收费。先要求 3–5 家雇主明确愿意为哪项节省付费。
2. **院校就业辅导试点**：按一届学生或一段辅导项目报价，交付导师协作、作品进展和汇总结果。需要先实现角色权限、明确授权与可解释的报告，再销售。
3. **后续可选服务**：真实的人工作品/CV 辅导可单独收费。课程推荐若有佣金必须标识，不能影响自然推荐；暂不优先搭建复杂订阅支付。

收益测算只能做假设：10 家客户 × RM399 = RM3,990 月收入，尚未扣除模型推理、托管、文件存储、客服、内容审核、任务设计、销售和税费。必须记录每个活跃用户成本、每个付费雇主人工服务时间和获客成本。若主要价值靠大量人工逐份修改，不能按廉价软件订阅承诺无限服务。

## 如何形成独立性

动效、Aurora、地球、LLM 摘要都容易复制。真正需要积累的是：本地雇主认可的任务库、可追溯的作品修改与反馈、持续更新的岗位技能映射、可撤回的授权，以及可证实的筛选时间改善。合作关系和经授权的反馈循环比“训练了一个 AI”更接近壁垒。

当前没有足够证据宣称模型训练成熟、测验有效预测工作表现，或评分公平。RunPod 是运行基础设施，不是质量认证。应准备脱敏且合法使用的 CV 测试集，分别测姓名/经历/技能提取准确率、遗漏率、虚构率、扫描件表现、人工修正时间，并比较不使用模型的基线。未做这些验证前，使用“AI 辅助整理，需要本人审核”。

## 本次已直接落实

- 首页与 Dashboard 增加免注册工作练习入口：数据分析、客户体验、可持续运营三个具体情境。
- 练习包含任务说明、编辑区、逐项自检、参考思路、草稿下载；切换任务保留当前页面中的草稿。明确是虚构练习、自我审核，不产生认证、不自动发给雇主。刷新会丢失内存草稿，页面明确提示。
- 桌面双栏、手机单栏、原生模态焦点范围、Escape 关闭与焦点返回；修正全站样式引发的窄弹窗和悬停低对比。
- 删除首次 Dashboard 前重复且没有容错的学习组件初始化，保留首屏后的可选组件容错。
- 删除申请入口及提交时自动标记 CV“已审核”的行为；未经审核先进入 CV 审核页。
- 新申请默认不勾选 CV/PDF 分享；编辑已有申请保留原授权。缺失个人信息不再以演示人物代填。
- 导入 JobStreet 职位改为原站申请入口；服务端不再伪造站内投递记录。旧的无接收方记录标识为投递未确认，保留可撤回操作。
- 收据不再生成虚构编号，分享摘要不称为“已验证技能”；浏览进度不再统一称为完成。

## 全流程审查与后续优先级

| 流程 | 本次检查/处理 | 仍需升级或验证 |
|---|---|---|
| 首页 → Quiz → Earth | 代码与现有页面入口审查；新增直接试做入口，减少只有观看的体验 | 小样本访谈：用户能否在 30 秒内说明产品用途；测验与 Earth 不应阻断 CV / 求职 |
| 登录 → Dashboard | 启动容错回归测试；移除重复初始化 | 真机弱网、会话过期、第三方脚本被拦截；所有身份的完整端到端回归 |
| 个人资料 → PDF → 审核 | 检查独立页面与申请前审核门槛；现有隐私/路由回归 | 扫描 PDF、多语言、长 CV 的提取评估与错误定位；真实模型质量尚未验收 |

| 手机/平板 | 新练习桌面及手机浏览器实际查看 | 不等于所有设备/全部旧页面通过；真实 Safari、Android、键盘与读屏还需覆盖 |

## 30 天验证计划

第一周：访问 20 位毕业生、5 家 SME、2 位院校辅导人员；观察实际找工作过程，不只问“喜欢吗”。
第二周：选择两个岗位族，与愿意参与的雇主共同定义任务和人工审核标准。匿名比较“CV 单独审核”和“CV + 作品”的时间与判断理由，不用敏感身份特征排序。
第三周：让小范围用户完成探索→作品→本人审核→申请，记录卡住的位置。指标定义为完成率、主动返回率、纠错时间、授权理解率、雇主审核分钟数；不把点击量当就业效果。
第四周：提出真实付费试点报价。保留/调整的依据是愿意付费的客户及可重复交付价值，不是页面好看或口头赞赏。若企业只要更多简历，应重新验证定位，不继续堆功能。

## 测试边界

自动化使用合成数据和隔离数据库。没有向真实雇主提交申请，没有修改真实 CV 或训练模型。新增练习不调用 AI，不向服务器发送草稿。浏览器验证只覆盖本次明确列出的路径；这份审查不是全站生产认证。正式上线前仍需补充部署、真实邮件、外部服务失败、数据保留与恢复、支付（若未来启用）以及各角色的验收。

验证记录：19 项 Node 回归 + 2 项外部申请测试 + 11 项 CV 路由 + 15 项 CV 隐私测试通过（共 47 项）。浏览器确认首页与 Dashboard 入口、空草稿提示、任务切换保留草稿、390px 手机布局、首次演示登录显示姓名与 Dashboard，以及实际下载的 Markdown 草稿内容。Python 语法与 Git diff 检查通过。没有重跑所有仓库测试，也没有把三个练习称为 AI 评估。
