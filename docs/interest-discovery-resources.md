Mappings above are our educational interpretations, not provider endorsements,
UN certification or evidence that a global SDG has been achieved. Stamps use the
same self-reported Completed status as career learning. Only the waste course has
an included duration (8 hours) verified on its page; unknown durations are not invented.

Recommendations use chosen interests, saved/started/completed learning and collected
stamp themes. New-account tie order is varied by account ID; it is exploratory
ordering, not a claim about the learner's personality or a prediction from their CV.
Topics and completion records are stored per account in localStorage, using the
same learning records as reminders and passport stamps. No external AI call is needed.
