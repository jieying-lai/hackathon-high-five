# CareerLens competitor monitoring — manual preparation

Prepared 2026-10-23. No subscriptions, notifications or connected-service changes have been activated.

## Monthly source checklist

- JobStreet Malaysia: https://my.jobstreet.com/employer-benefits and https://my.jobstreet.com/about/responsible-ai
- Hiredly Malaysia: https://my.hiredly.com/ — review exploration, employer culture and Work Persona entry points.
- MYFutureJobs: https://myfuturejobs.gov.my/ — free support, skills/location matching and training.
- Teal: https://www.tealhq.com/pricing
- Huntr: https://huntr.co/pricing

For each review, record the date, exact official URL, changed capability or price, billing period/currency, and whether an actual buyer problem requires a product change. Do not equate absence from a marketing page with absence of a feature.

Pair competitor changes with pilot evidence: completed real actions, repeat use, actual paid commitments, and employer review time. Avoid chasing features solely because a competitor announces them.

Optional activation, only after the user selects a destination: prepare alert searches and a bookmark bundle for email, Slack/Teams or a monthly manual review. Credentials must use the normal integration/secrets flow, never this document.
