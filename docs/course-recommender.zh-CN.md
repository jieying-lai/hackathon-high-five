# 学习课程推荐模型

## 已实现

“Explore a new side of you” 默认从数据集的 5,014 门去重课程推荐，每次三门。
用户可选八种兴趣、输入英文学习关键词、收藏、开始学习、标记完成或点击“不感兴趣”。
“换一批推荐”排除近期展示过的课程，不把换批自动当成负面反馈；“不感兴趣”才会排除该课并降低相似课程的排序。
“不感兴趣”仅请求并替换该位置的一张课程卡，其他卡片 DOM 和展开状态保留。请求会排除当前显示的其他课程，避免重复。
收藏或更新学习状态不会自动换掉推荐课程。修改兴趣、提交新关键词或点击“换一批推荐”才重新获取一整批；显式重置反馈也会重新推荐。
已完成课程不再推荐；“重置反馈”清除不感兴趣及近期展示记录，不清除兴趣或学习进度。
My Growth 现在分成 Reskilling Plan、Explore Learning、Saved Courses、Completed Learning、SDG Passport 五个独立页面视图。
学习页面切换栏滚动时吸附在主导航下方；窄屏可横向滑动切换栏。
探索推荐区移除重复的 Passport 和 Saved Courses 快捷按钮，统一使用上方切换栏。
探索课程的收藏按钮改为空心/实心爱心，收藏状态仍写入同一份 Saved Courses 记录。
Reskilling Plan 的步骤使用横向滚动卡片；推荐理由折叠，结果说明保留在卡片正面。
番茄钟改为左下角可拖动悬浮窗，在 Reskilling Plan 和 Explore Learning 显示。
首次以小窗展示，支持展开、收起、拖动标题栏；聚焦标题栏后方向键移动，Home 回到左侧。
展开时可拖动右下角手柄改变宽高，窄小尺寸会缩小番茄图并允许内容滚动。尺寸和位置一起保存；双击手柄恢复默认大小。聚焦手柄后可用方向键调整，Home 恢复默认尺寸。
位置按账号保存在本机浏览器，计时状态保存在当前标签页。两个页面共用同一实例，切换时不会重新开始或重复计时。
Completed Learning 汇总职业课程及额外课程，支持按来源筛选、按完成日期排序、重温课程。
完成课程按链接去重；旧记录没有完成日期时显示“未记录”，不伪造完成日期。学时仅累计已有课程估算。
Saved Courses 统一收录职业路径课程及额外课程，并标明来源。计划页不再显示独立的 Saved for later 栏。
旧收藏无需重新保存；在刷新或换批后仍显示，推荐页面的 Saved Courses 按钮可直接跳转。
收藏卡支持开始/继续学习、更新学习状态和移除收藏。移除只取消收藏，保留学习进度；推荐失败时收藏区仍可使用。
旧版已保存的课程可从原有本地记录恢复课程名称和链接，后续保存会补充来源和分类。
反馈按账号保存在当前浏览器，不会跨设备同步。不同账号使用不同的冷启动排序。

## 模型是什么

这是内容推荐模型，训练算法是 TF-IDF（单词及相邻双词）拟合课程语料，再使用余弦相似度、反馈向量和多样性排序。
它不是大语言模型微调，也没有训练出经验证的协同过滤或点击率预测模型。
没有课程配对喜好标注，所以不编造用户-课程训练标签，不提供虚构准确率。
没有使用 CV、SDG 标签、年龄或健康等个人特征。

训练产物：

- `models/course-recommender/model.json`：约 8.5 MB，28,865 个语料词项、课程向量及课程资料。
- `models/course-recommender/training-summary.json`：输入哈希、训练时间、行数和方法限制。

第二份数据的 420 条记录只拟合平台层面的满意度和完成率平滑先验，排序权重很小。
平台先验不是个人对具体课程的喜欢程度。平台名不匹配时使用中性值。
运行只使用 Python 标准库及网站已有 Flask，不需要 GPU、API key、新模型下载或额外推荐依赖。
模型文件放在仓库 models/ 下，可随 GitHub 项目分发。原始 ZIP 不放入 Git。

## 运行和重新训练

正常启动网站即可加载已拟合模型；后端有改动时需重启网站进程。
在 Talent Portal → My Growth → Explore Learning 使用推荐区域。Saved Courses 查看收藏。
模型加载失败会显示错误和重试入口，不伪装成 AI 推荐。

重新训练（在项目根目录执行；RunPod 或本机都可）：

```bash
python scripts/train_course_recommender.py --courses "online learning platform.zip" --usage "online platform lesser.zip"
```

原始文件可放任意目录，通过完整路径指定。只需 Python 3.10+，不需要重新运行 SDG 标注。
训练后重新启动网站，清除进程内旧模型缓存。

## 接口

`POST /api/discovery/recommend`，需要 Talent 登录及网站现有 CSRF 保护。
接收 `interests`、`query`、`liked`、`disliked`、`exclude`、`round`。
服务器从登录会话获取账号，不接受客户端指定其他用户身份。
响应包含真实课程链接、来源、课程介绍和匹配词解释。
模型只返回目录课程，不生成课程或链接；SDG 字段为空，不自动盖章。
护照仍可访问先前已有映射的学习资源。

## 当前边界

英文关键词效果更直接；界面有中英马来文，按钮兴趣映射到英文检索词。
推荐课程的费用、语言、可访问性以提供方当前页面为准，不把所有课程都称为免费。
尚未运行准确率评测或浏览器端到端测试，不能宣称模型已验证用户满意度。
后续可收集用户明确授权的课程喜好配对数据，再训练神经重排模型。
SDG 自动标注在独立流程处理，不阻塞推荐。
