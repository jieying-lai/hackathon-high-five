# 候选人技能与资质对比：实现与联动说明

本模块直接运行于现有 Flask、Jinja、原生 JavaScript 和 Tailwind 项目，无须新增前端构建系统或外部图表服务。

## 页面布局

- Employer Portal → Overview：原有统计卡片、Open vacancies 和 Screening pipeline → 页面最下方的职位选择框与前三名领奖台。
- 领奖台在桌面端按第 2、第 1、第 3 名展示，第一名金色且最高，第二名银灰，第三名铜色。窄屏优先显示第一名。少于三人时保留明确的空位。
- Employer Portal → Candidate Skills & Qualifications Comparison：筛选栏 → 学历饼图与技能覆盖条形图 → 简历资质明细 → 面试回复记录。
- 公司名称从当前登录 HR 的 `role_details.company_name` 读取，显示在 HR 当前公司工作区标识中。Logo 保留 CareerLens AI 平台身份，无底部 footer。
- 平台支持多家公司；Employer 页面按当前登录账号展示该公司的职位、部门、候选人及面试回复，不能跨公司查看私有招聘数据。本轮仅调整 Employer 页面，不修改首页或求职者页面。
- 删除旧的 All industries / Insurance / Technology 等跨公司行业预设。部门选项来自当前公司实际发布的职位，不根据候选人技能猜测公司部门。

## 数据边界与提取

`GET /api/hr/candidate-comparison?demo=0` 仅限 HR 角色，按会话中的公司所有者 ID 连接该公司的职位和投递记录，仅纳入授权分享整理后简历摘要的候选人。不会返回其他公司的投递或个人原始 PDF。

默认演示公司可以显式勾选包含合成候选人，所有合成记录标为 Demo；其他公司即使自行添加 `demo=1` 参数也无法获得示例名单。正式模式没有数据时显示空态，不借用另一公司的名单。

候选人按实际投递职位关联 Department / Position。页面已移除 Field / Industry，避免把行业标签当作公司部门。部门先筛选，岗位下拉仅显示该部门的职位。选择部门会清除原岗位限制，从而比较该部门各职位的候选人。一个人投递多个职位时，选中具体职位后按该职位比较；合并情形中每人只计一次，保留最高匹配记录。

PDF 解析复用现有词库：硬技能、软技能、最高学历、教育经历中的院校/专业、工作经历文本、行业。无法识别的院校或专业保留为空（页面显示 —），不会凭空补全。博士不会再被并入硕士。学校名称本身不会被当作本科学历证据。

经验为简历声明的年数，不是已核实的特定岗位任职时长；缺乏明确年数证据时显示待确认，不能通过有最低年数要求的筛选。经历文本保留给 HR 判断相关性。规则解析尚不支持对扫描图片进行 OCR；模糊、复杂排版的简历需要 HR 复核。

学历统计始终包含 SPM / UEC、Undergraduate、Master、Doctor、Intern / Trainee，另有 Other / To confirm 防止将 Diploma、未知学历错误归类。Intern / Trainee 是身份状态，已知最高学历优先，避免将实习生已有学位抹去。最低学历筛选不对未知学历做猜测。

## 状态如何联动

1. 获取一次当前公司候选人和职位数据，网络请求使用递增版本号，较晚返回的旧请求不能覆盖新状态。
2. `state` 保存 vacancy、department、years、education、sort、query。
3. 输入、下拉选择触发 `set(key, value)`，先按职位、部门、最低年数、最低学历及搜索词求交集，再对候选人去重。
4. 同一份筛选结果生成：候选人数、学历人数/百分比、岗位技能简历覆盖人数、前三名个人岗位技能覆盖率、资质表格、Overview 领奖台。
5. 列表支持匹配度、经验高到低、学历高到低；领奖台始终依据岗位匹配分数排名，避免把“学历最高”误称为“岗位最匹配”。并列时按候选人 ID 保持稳定顺序，并非声称两人的质量不同。
6. Overview 的职位选择同时更新岗位筛选、领奖台和原有筛选流程统计。对比页面切换职位也会更新 Overview 对应职位。
7. 学历图用 SVG 原生 tooltip 提供人数与百分比，可通过鼠标悬停或键盘聚焦扇区查看。全零时显示中性空圆。技能图表示简历证据覆盖率，不表示实测技能掌握度。
8. 邀请按钮沿用已有面试弹窗与站内通知。正式候选人须实际投递本公司职位，服务端再次校验归属；示例名单仅默认演示公司可用。

## 验证与运行

运行方法保持 README 中现有方式：项目虚拟环境运行 `src/main.py`，登录 HR 后打开 Overview 或 Candidate Skills & Qualifications Comparison。

自动验证覆盖公司隔离、角色权限、简历分享授权、学历标准化、未知值处理、硬软技能、筛选、两种排序、饼图人数及百分比、领奖台 2–1–3 顺序、职位切换、空状态和完整概览启动流程。

图表、排名与筛选通过 DOM 验证；尚未在真实浏览器中完成此版的视觉截图验收。课程学习、面试通知等既有模块继续使用原有后端。
