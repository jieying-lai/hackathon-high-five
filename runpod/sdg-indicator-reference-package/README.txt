UN SDG indicator metadata reference

Contents:
- un-sdg-indicator-metadata.jsonl: text extracted from the DOCX files in the supplied
  SDG-indicator-metadata.zip. It contains 267 indicator metadata documents across Goals 1-17.

This is an official indicator-reference corpus, not a course-label training set. Use it
to retrieve relevant goal/target/indicator definitions for a course, then require actual
course-description evidence before assigning topic-specific SDG labels. Retrieve only a
small set of matching records per course to keep runtime memory and prompt size low.

Source: United Nations Statistics Division SDG Indicators Metadata Repository
https://unstats.un.org/sdgs/metadata/
