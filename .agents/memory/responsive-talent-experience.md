---
name: Responsive talent experience
description: User expectations for phone layouts in the talent dashboard and work-life atlas.
---

The talent dashboard must fit the available screen, and the work-life atlas must remain readable in portrait phone layouts without overlapping panels or letter-by-letter text wrapping.

Secondary navigation must also fit phones across Explore Careers, My Profile and My Growth. Keep the work-life atlas accessible from navigation rather than a dashboard promotion. Remove redundant and internal-facing copy without removing useful actions or privacy/consent explanations.

Apply the same viewport-fit requirement to the company workspace: secondary tabs, company profile actions, header controls and account dialogs must remain readable and usable on phones.

**Why:** The user repeatedly reported unreadable dashboard content and overlapping atlas content on phones.

**How to apply:** Check narrow phone widths as well as desktop when changing these screens. Verify actual rendered layout rather than relying only on stylesheet assertions.
